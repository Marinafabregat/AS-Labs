Frequently Asked Questions

What is VINSEC?

VINSEC is a second-hand online marketplace project combining Vinted features with web application security controls.

How are user permissions handled?

Permissions are divided into 3 levels: Users (Level 1), Moderators (Level 2), and Admins (Level 3) managed via JWT sessions and access rules.

How do I request moderator status?

Standard users can submit a petition through their dashboard once logged in. Administrators review and approve requests.
